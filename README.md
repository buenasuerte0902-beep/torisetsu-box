# 取説BOX

家電・家具の取扱説明書（写真・PDF）と型番・購入日・保証期限などのメモを、
スマホから1か所にまとめて保管できるPWA（インストール可能なWebアプリ）です。

- 説明書のページをその場で撮影、または手元のPDFファイルを取り込んで保存
- 名前・メーカー・型番・メモで検索、カテゴリ（家電/家具/その他）で絞り込み
- 保証期限が近い/切れている項目をひと目でわかるバッジ表示
- **データはすべて端末内（IndexedDB）に保存**。サーバー不要・アカウント不要・完全オフラインで動作
- 別の端末に移したいときは、書き出し（エクスポート）→読み込み（インポート）で手動移行

サーバーを持たない・端末内完結の設計にしているのは、将来的にPWABuilderやCapacitorで
ラップしてApp Store / Google Playに公開することも視野に入れているためです
（サーバー依存が無いほうがそのままアプリ化しやすい）。

## 使い方（開発確認・インストール）

```bash
python serve.py --tls --lan
```

表示された `https://<LAN-IP>:8790/` をスマホで開き、自己署名証明書の警告が出たら
「詳細設定」→「このサイトにアクセスする」で進んでください（Service Worker登録・
PWAのホーム画面インストールには安全なコンテキスト = HTTPSが必要なため）。

開いたページを「ホーム画面に追加」すればアプリのように使えます。一度インストールすれば
Wi-Fiが無い場所でも（=サーバーを起動していなくても）完全に動作します。

外部に公開する必要はありません（サーバーが無いため公開先という概念自体がありません）。
GitHub Pages に置いても同様に動きます。

## 複数端末で使いたい場合

このアプリはサーバーを持たないため自動同期はしません。別の端末に説明書データを
移したいときは、右上の 📤（書き出し）でJSONファイルとしてダウンロードし、
別端末を開いて 📥（読み込み）でそのファイルを選ぶと取り込まれます
（同じIDのデータは重複登録されないので、同じファイルを何度読み込んでも安全です）。

## 構成

- `index.html` / `css/app.css` / `js/{app,db,export,util}.js` — フロントエンド（バニラJS、ビルド無し）
- `js/db.js` — IndexedDBラッパー（`items`テーブルと`files`テーブル。写真/PDFはBlobのまま保存）
- `js/export.js` — 全データ（写真/PDFの実体込み）をJSON1ファイルに書き出し/読み込み
- `manifest.json` / `sw.js` / `icons/` — PWA化。Service Workerはアプリシェルをキャッシュし
  完全オフラインで動作（データはIndexedDBなのでネットワーク自体が不要）
- `serve.py` — 開発確認・他端末へのインストール用の静的配信サーバー（データのやり取りはしない）
- `tools/make_icons.py` — アイコン生成スクリプト（Pillow使用）

## 既知の限界

- 自動での複数端末同期はありません（手動エクスポート/インポートのみ）
- ブラウザの「サイトデータを消去」やアプリのアンインストールで、IndexedDB内のデータも
  一緒に消えます。定期的なエクスポートでのバックアップを推奨します
- エクスポートファイルは写真・PDFをBase64で埋め込むため、データ量が多いとファイルサイズが
  大きくなります

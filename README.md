# 取説BOX

家電・家具の取扱説明書（写真・PDF）と型番・購入日・保証期限などのメモを、
スマホから1か所にまとめて保管できるPWA（インストール可能なWebアプリ）です。

- 説明書のページをその場で撮影、または手元のPDFファイルを取り込んで保存
- 名前・メーカー・型番・メモで検索、カテゴリ（家電/家具/その他）で絞り込み
- 保証期限が近い/切れている項目をひと目でわかるバッジ表示
- サーバー（Flask + SQLite）にデータを持つので、**自宅の複数端末から同じ内容を見られる**
  （スマホ・タブレットなど、同じWi-Fi内から同じURLを開けば同期される）

## 使い方（最初の起動）

```bash
pip install -r requirements.txt
python server/app.py --tls --lan
```

表示された `https://<LAN-IP>:8790/` を同じWi-Fi内のスマホで開きます。
自己署名証明書の警告が出たら「詳細設定」→「このサイトにアクセスする」で進んでください
（カメラ撮影・PWAインストールにはHTTPSが必要なため、自己署名証明書を使っています）。

初回はパスワード入力画面が出ます。既定値は `torisetsu-box-1234` です
（環境変数 `APP_PASSWORD` を設定すると変更できます。家族以外もアクセスできるネットワークで
動かす場合は必ず変更してください）。

スマホでは、開いたページを「ホーム画面に追加」するとアプリのように使えます。

## 複数端末で同期したい場合

このFlaskサーバーが動いている間だけ、そのサーバーを起点にデータが共有されます。

- **自宅内だけで使う** → PC等で `python server/app.py --tls --lan` を常時起動しておき、
  各スマホ/タブレットから同じ `https://<LAN-IP>:8790/` を開く
- **外出先（モバイル回線）からも使いたい** → このFlaskアプリはそのままRender / Fly.io /
  PythonAnywhere 等の無料枠にデプロイできます（`server/app.py` をWSGIアプリとして起動し、
  `data/` ディレクトリを永続化できるプランを選んでください）

## 開発用の軽量起動（アップロード不要な確認だけしたい場合）

```bash
python server/app.py
```

`http://127.0.0.1:8790/` でPCから確認できます（カメラ撮影・位置情報系の機能は使わないため
HTTP起動でも動作しますが、実機のカメラを使うにはHTTPSが必要です）。

## 構成

- `index.html` / `css/app.css` / `js/{app,api,util}.js` — フロントエンド（バニラJS、ビルド無し）
- `server/app.py` — Flask本体。静的ファイル配信・ログイン・アイテムCRUD・写真/PDFアップロードAPI
- `server/db.py` — SQLite（`data/app.db`、初回起動時に自動作成）
- `data/uploads/` — アップロードされた写真・PDFの保存先（gitignore対象）
- `manifest.json` / `sw.js` / `icons/` — PWA化（アプリシェルのみキャッシュ、データは常にサーバーから取得）
- `tools/make_icons.py` — アイコン生成スクリプト（Pillow使用）

## 既知の限界

- オフライン時は新規追加・閲覧ができません（アプリの見た目=シェルはキャッシュされますが、
  説明書のデータ・写真・PDFは常にサーバーから取得する設計のため）
- パスワードは家族内共有用の簡易的なものです。より強固な認証は想定していません
- 1ファイルあたり25MBまで（`server/app.py` の `MAX_CONTENT_LENGTH`）
